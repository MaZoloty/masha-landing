# Visual Direction

## Source

This visual direction is based on the approved homepage hero reference provided in the project chat.

The reference is the design target for the next rebuild of the website visual system. Future pages should not copy it blindly, but must preserve its mood, hierarchy, restraint, and component logic.

## Product Mood

The website must feel like a premium consulting brand for beauty and wellness businesses.

It should not look like:

- a rough MVP;
- a generic SaaS dashboard;
- a Tilda template;
- an infoproduct landing page;
- a beauty salon promo site with decorative feminine cliches;
- a portfolio for "pretty websites";
- a heavy analytics product.

It should feel like:

- premium strategic consulting;
- editorial clarity;
- light dashboard intelligence;
- structured, calm, high-trust design;
- elegant but modern;
- a system built by a person who understands service businesses, not just websites.

## Core Visual Concept

The visual direction is:

> Premium consulting + light dashboard.

The homepage hero and future sections should look like a polished strategic system:

- large elegant editorial serif hero typography;
- clean sans-serif UI text;
- warm ivory / milk background;
- soft lilac accent cards;
- pale butter accent cards;
- thin grid lines;
- dark premium pill CTA;
- light analytical visuals;
- lots of whitespace;
- curated, calm, high-end feeling.

## Approved Hero Reference Characteristics

The reference hero uses:

- a large rounded outer shell with thin lavender-gray border;
- a top navigation band separated by thin grid lines;
- wide editorial left column with a large serif headline;
- small calm sans-serif body copy;
- one primary black pill CTA;
- bottom proof row with small signal dots and vertical separators;
- right-side analytical card cluster;
- overlapping lilac and butter cards;
- thin line charts, path diagrams, signal dots, and simple bar indicators;
- large subtle circular/curved linework in the background;
- almost no heavy shadows;
- no decorative icon noise;
- no bright colors.

This is the reference for the homepage hero and the visual DNA for the rest of the site.

## Design Principles

1. Air and restraint over density.
2. Typography is the main luxury signal.
3. Use graphic clarity, not decorative noise.
4. Cards must feel curated, not generic.
5. Every visual element must have a role.
6. The site should feel expensive, calm, and strategic.
7. Data-like visuals should feel light and editorial, not technical-heavy.
8. The system must stay useful: beauty comes from clarity, proof, and decision support.

## Page-Level Direction

### Homepage

The homepage should be the strongest expression of the visual direction.

Use:

- editorial serif hero;
- large ivory canvas;
- thin grid shell;
- dark premium CTA;
- strategic insight cards;
- proof row;
- light dashboard card cluster;
- cases and experience as primary proof.

The homepage should feel like:

> An expert consulting system that helps beauty/wellness businesses find where bookings are leaking.

Do not make the homepage:

- a personal blog;
- a decorative beauty landing;
- a generic service portfolio;
- a dense dashboard.

### Internal Pages

Internal pages should inherit the same visual DNA, but can be simpler.

Use:

- serif page titles;
- clean section grids;
- ivory background;
- curated cards;
- thin line dividers;
- enough whitespace;
- restrained analytical visuals where they help explanation.

Internal pages should not create a new visual style. They should feel like they belong to the same strategic system as the homepage hero.

### Diagnostic Sections

Diagnostic sections should lean more into light dashboard intelligence while staying premium and editorial.

Use:

- mini-audit cards;
- score controls that feel calm and curated;
- result summary blocks;
- priority cards;
- soft signal dots;
- subtle chart/path visuals;
- clear next-step CTA.

Do not use:

- raw forms;
- cramped controls;
- quiz-like styling;
- empty calculator placeholders;
- scary warning colors;
- dense technical dashboards.

## Prohibited

Do not use:

- generic SaaS cards everywhere;
- blue startup colors;
- random gradients;
- heavy shadows;
- small cramped text;
- icon packs used decoratively;
- harsh red/yellow warning colors;
- stock illustration style;
- multiple unrelated border radii;
- overly rounded cute UI;
- dense layouts with little whitespace;
- beauty cliches like lashes, flowers, sparkles, glossy feminine tropes;
- sections styled independently from the approved hero reference.

## Desired Emotional Response

The user should feel:

- "This looks like a premium expert product";
- "This is structured and intelligent";
- "This person understands systems, not just websites";
- "It feels high-end, calm, and trustworthy";
- "This is for a serious beauty/wellness business, not for a cheap template site".

## How To Use

Use this file as the first visual filter before designing or coding any public page.

If another document conflicts with this direction, this file wins for visual mood. `docs/design-system.md` translates this direction into tokens and component rules. `docs/component-architecture.md` defines how sections and components should be organized across the site.

Before implementing any section, answer:

1. Which component pattern from the design system is being used?
2. Does the section visually relate to the approved hero reference?
3. Which typography decision creates the premium/editorial signal?
4. Which accent card, if any, has a real informational role?
5. Which data-like element helps the user decide?
6. Which visual details can be removed to increase restraint?
7. Does the screen still feel personal and expert, not faceless SaaS?

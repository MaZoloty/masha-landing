# Visual Acceptance Rules

Проект должен соответствовать направлению:
premium consulting + light dashboard.

## Должно ощущаться

- дорогой консалтинг
- лёгкая аналитика
- beauty/wellness без клише
- спокойная экспертность
- не MVP, не SaaS-шаблон, не Tilda

## Hero

- крупный editorial serif-заголовок
- тёмная pill CTA-кнопка
- справа аналитические карточки lilac/butter
- много воздуха
- нет перегруза
- следующий блок слегка виден

## Диагностика

- выглядит как мини-аудит, а не тестик
- 12 карточек читаются легко
- оценка 0–3 понятна
- результат выглядит как dashboard
- карта решений подана через пользу, не как “купи PDF”

## Запрещено

- случайные цвета
- новые радиусы без системы
- тяжёлые тени
- дешёвые иконки
- плотные серые карточки
- прямые продажные заголовки с ценой
- блоки, похожие на черновик

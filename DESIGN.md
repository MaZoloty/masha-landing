# Design

Визуальная система mazoloty.ru. Концепция: **премиальный консалтинг + лёгкий дашборд**. Источник настроения — `docs/visual-direction.md`; правила и компоненты — `docs/design-system.md`; живые токены — `assets/ui-system.css` (префикс `--ui-*`). Этот файл — сводка для агентов; при изменении токенов обновлять и его.

## Theme

Тёплая, светлая, редакционная. Айвори-фон, тонкие лавандовые линии сетки, крупный элегантный serif в заголовках, тёмная pill-кнопка CTA. Почти без теней, без ярких цветов, без декоративного шума. Контраст строится типографикой и воздухом, не насыщенностью.

## Typography

- Display / заголовки: `--ui-font-display` — **Cormorant Garamond** (fallback Lora, Georgia). Элегантный контрастный serif с кириллицей. Hero-заголовок — самый сильный визуальный элемент страницы.
- UI / текст: `--ui-font-sans` — **Manrope** (fallback Inter, Segoe UI). Навигация, кнопки, параграфы, формы, карточки.
- Body ≥ 16–17px, line-height ~1.7. Маленькие uppercase-лейблы — для категорий и секций. Метрики — display-serif или сильная числовая типографика, всегда с подписью и интерпретацией. Ширина текстовых блоков 680–760px.

## Layout & Spacing

- Контейнеры: shell 1380px (`--ui-container-wide`), контент 1220px (`--ui-container`), чтение 740px (`--ui-container-reading`).
- Внешняя оболочка страниц — `.ui-shell`: скруглённый контур с тонкой лавандовой рамкой и линиями сетки.
- Шкала отступов 4/8px (`--ui-space-1` … `--ui-space-28`). Секции на десктопе 80–112px, на мобиле 48–72px. Щедрый воздух обязателен.
- Радиусы: `--ui-radius-sm` 12 / `md` 20 / `lg` 28 / `xl` 36 / `pill` 999. Не смешивать посторонние радиусы.
- Тени только токенные: `--ui-shadow-card`, `--ui-shadow-lift` — мягкие и редкие.
- Hero — асимметричная редакционная сетка; внутренние секции — чистая модульная сетка; без карточек-в-карточках, кроме настоящих метрик/полей/повторяемых элементов.

## Components

Собирать страницы только из паттернов `assets/ui-system.css` и `docs/component-architecture.md` (галерея: `components.html`). Ключевые: `.ui-shell`, `.ui-header`, `.ui-container*`, `.ui-section*`, `.ui-grid--2/3`, `.ui-type-display/title/body`, тёмная pill-CTA, акцентные lilac/butter карточки, proof-строка с сигнальными точками, тонкие линейные графики и path-диаграммы. Новый компонент — сначала в систему, потом на страницу.

## Motion

Токены: `--ui-motion-fast` 160ms, `--ui-motion-enter` 280ms, `--ui-ease-out` cubic-bezier(.22,1,.36,1). Движение ориентирует, не украшает: короче ~300ms, кастомный ease-out (не ease-in), не анимировать частые действия, уважать `prefers-reduced-motion`. Для новой анимации использовать скилл `emil-design-eng`, для проверки — `review-animations`.

## Per-page notes

- Главная — сильнейшее выражение системы, hero-референс — визуальный якорь всего сайта.
- Внутренние страницы наследуют ДНК, но проще: serif-заголовки, айвори, тонкие разделители.
- `/diagnostika/` — отдельная система `docs/design-system-diagnostika.md`; больше «лёгкого дашборда», но премиально: без сырых форм, квизовости и пугающих цветов. Standalone-воронки не наследуют шапку сайта.

## Never

Дженерик SaaS-карточки, синие стартап-цвета, случайные градиенты, тяжёлые тени, мелкий текст, декоративные иконпаки, красно-жёлтые предупреждения, стоковые иллюстрации, «милые» перескругления, плотные секции без воздуха, beauty-клише (ресницы, цветы, блёстки).
